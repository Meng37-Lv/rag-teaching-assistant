# 注册登录与旧数据归属

手机号使用 11 位数字，数据库唯一；账户名称可重复，身份由不可变 account_id 确定。
密码按原样进行 PBKDF2-SHA256（600000 次、随机盐）哈希，不 trim，不设复杂度门槛。
登录产生 8 小时有效的随机 Bearer 会话；数据库只存凭证哈希。退出撤销当前会话。
前端凭证保存在当前标签页 sessionStorage，不放 URL；网页和桌面使用同一 Authorization 头。
生产联网传输应使用 HTTPS。sessionStorage 仍受 XSS 风险影响。

启动业务存储时执行版本化事务迁移：增加账户、会话及课程归属表，旧课程、文件、历史不删除、不重算。
新注册账户看不到任何旧课程，包括 default。旧课程在显式关联前不可从业务 API 访问。
无需为全局账户表增加 course_id；课程归属在 course_ownership 表中独立管理。

## 仅经授权执行旧数据关联

本轮未执行真实库迁移或关联。先在临时库测试、备份真实数据库和资料，再获得操作授权。
工具默认只读预览，必须显式指定数据库、稳定账户 ID 和每一个课程 ID：

```powershell
.venv\Scripts\python.exe scripts/assign_legacy_courses.py --database <绝对数据库路径> --account-id <目标账户ID> --course-id <旧课程ID>
```

获授权后在相同命令追加 `--apply` 执行；多个课程重复指定 `--course-id`。
关联在单一事务内执行，校验账户/课程存在，不允许覆盖其他账户已有归属。
重复关联到同一账户是幂等的。没有自动领取、网页领取或批量默认归属功能。
关联只写 course_ownership，不搬移资料、不重建向量库、不重算历史。

## 登录背景配置

服务端可配置 SCHOOL_AERIAL_IMAGE_URL（公开 HTTPS 图片地址或同站相对路径）。
未配置则使用简洁背景。仅公开这一个配置，不公开环境变量或其他配置内容。

## 会话与课程隔离

统一 FastAPI 依赖检查所有 /api 业务请求的会话及课程归属；列表按 account_id 查询。
课程路径、JSON 教学请求及 multipart 预览/上传均检查归属，再处理文件、模型或存储。
临时汇报材料仅存在于当前请求，解析后删除；不提供跨账户共享 ID 或文件下载入口。
业务导出下载同样带 Authorization。没有桌面免鉴权后门。

## 内部 store 边界

当前 HTTP 业务入口统一校验会话和课程归属后，才调用课程、材料、历史、学情和导出 store。
这些 store 方法属于内部接口，当前阶段没有对每个底层方法全面重构为携带 account_id。
未来新增后台任务、脚本入口或其他服务入口，必须复用同一账户归属校验，不得直接绕过授权访问账户业务数据。
公共 API 仅注册、登录、健康检查及公开背景配置；文档入口关闭。
